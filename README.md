# Habit Insight Lab

This project explores how daily habits such as sleep and physical activity relate to wellness indicators like stress and sleep quality.

The goal is to practice collaborative data analysis using Python, pandas, and Streamlit, while learning GitHub workflows.

---

## Questions We Explore

- Does sleep duration relate to sleep quality or stress?
- Does physical activity or daily steps relate to stress levels?
- Which habit appears to have the strongest association with wellness outcomes?

These analyses are exploratory and focus on patterns, not causation.

---

## Dataset

This project uses a publicly available dataset from Kaggle:

**Sleep Health and Lifestyle Dataset**

The raw dataset is stored under `data/raw/` and is not modified directly.

---

## Project Structure

- `data/raw/` – original dataset as downloaded
- `data/processed/` – cleaned and prepared data
- `src/` – data loading, cleaning, and analysis logic
- `app/` – Streamlit application code
- `notebooks/` – exploratory analysis

---

## Collaboration Workflow

- No direct commits to `main`
- All work is done on feature branches
- Changes are merged via Pull Requests
- Small, focused commits are preferred
